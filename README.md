# Sahithi Aekka — Cloud Engineer Portfolio

Personal portfolio site showcasing cloud architecture projects, certifications, and experience.

**Live site**: [sahithiaekka.github.io/sahithi_portfolio](https://sahithiaekka.github.io/sahithi_portfolio/)

## About

Sahithi Aekka is a Cloud & DevOps Engineer with experience in AWS, Kubernetes, Terraform, and CI/CD automation. MS in Computer Science from the University of Michigan.

## Tech

Single-file static site — HTML, Tailwind CSS, vanilla JS. Deployed via GitHub Actions to GitHub Pages.

## Testing

23 automated Playwright tests run on every push — covering structure, links, styling, theme toggle, and responsive layout. Deployment is blocked if any test fails.
